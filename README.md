# ⚡ Portfolio V1 - Minimalist & Cyberpunk

Un portfolio personnel axé sur l'esthétique minimaliste, la typographie premium et des interactions subtiles inspirées de la culture Cyberpunk/Hacker.

## 🎯 Vision du projet
L'objectif est de créer une expérience utilisateur marquante où le contenu respire, soutenu par des animations fluides et réactives aux actions de l'utilisateur.

## 🛠️ Stack Technique
* **HTML5** (Sémantique et accessible)
* **CSS3** (Grid, Flexbox, Animations, Variables CSS)
* **JavaScript (Vanilla)** (Manipulation du DOM, Effets interactifs réactifs)

## 🚀 Installation & Lancement local
1. Cloner le dépôt : `git clone https://github.com/ton-pseudo/portfolio.git`
2. Ouvrir le projet dans VS Code.
3. Lancer via l'extension **Live Server**.
